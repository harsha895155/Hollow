## ✨ Core Features

- **Financial Intelligence**: Automatically analyzes your spending velocity and capital allocation to provide intelligent system insights.
- **Master Ledger**: A beautiful tracking system for all your income and expenses, featuring custom categorizations and visual tagging.
- **Dynamic Aesthetic Engine**: Fully responsive design with an animated Cyber-Nebula (Dark Mode) or Infinite Spectrum (Light Mode) background.
- **Capital Allocation Visualization**: Interactive pie charts powered by Recharts for deep, visual tracking of where your resources flow.
- **Export & Reporting**: Generate a comprehensive "Financial Intelligence Briefing" and securely print or export it to PDF.
- **System Preferences**: Seamlessly toggle between Night/Light mode, Compact Layout for high-density viewing, and global Currency adjustments (INR ₹ / USD $).

## 🛠️ Technology Stack

- **Frontend Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Data Visualization**: [Recharts](https://recharts.org/)
- **Iconography**: [Lucide React](https://lucide.dev/)

## 🚀 Quick Start

Follow these steps to deploy hollow locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/Hollow.git
   cd Hollow
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Initialize the development server**
   ```bash
   npm run dev
   ```

4. **Access the application**
   Navigate to `http://localhost:5173` in your web browser.

## 🔐 Data Privacy 

Hollow is a fully local client-side application. No financial data is sent to external servers. All ledger entries and configuration preferences remain active on your local device, ensuring maximum privacy and security.
